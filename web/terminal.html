Claude Code

使用说明
通过远程服务器中转，连接到 Mac 上运行的 Claude Code，直接操作对应项目目录下的文件。AI 调用、文件读写、命令执行都在 Mac 完成。
页面功能
- 输入框：发送 prompt，按 Enter 或 ▶ 发送
- 停止 (■)：中断 Claude / 关闭弹出菜单
- 同步：重启 Claude，加载 Mac 上最新对话
- Files：浏览项目文件、上传/下载
- 附件 (📎)：选图发给 Claude（输入框也支持粘贴截图）
快捷键工具栏
- Esc / Tab / ↑↓←→：发送到终端
常用命令：/help、/cost、/compact、/clear
